## 📖 О проекте

Полноценный классический интернет-магазин, разработанный на Django. Проект включает в себя каталог товаров, систему аутентификации, продвинутую корзину с проверкой складских остатков и полный цикл обработки заказов. Кодовая база покрыта автотестами на 100% и отформатирована современным линтером Ruff.

### 🌟 Основной функционал
- **Пользователи**: Регистрация, авторизация, управление профилем (с нормализацией данных), просмотр истории заказов. Защита от несанкционированного доступа (IDOR).
- **Каталог товаров**: Главная страница с витриной, детальные карточки товаров, отображение актуального наличия.
- **Корзина**: Добавление/удаление товаров, динамическое изменение количества (с защитой от превышения складских остатков).
- **Заказы**: Оформление с фиксацией цен, автоматическое списание товаров со склада. Возможность отмены созданного заказа с возвратом товаров на баланс склада.
- **CLI-инструменты**: Кастомные management-команды для управления складом через консоль.

## 🚀 Запуск проекта

Проект поддерживает два удобных сценария запуска: полностью в изолированных контейнерах (рекомендуется для быстрого старта) или гибридный режим для локальной разработки.

### 1. Подготовка окружения
Склонируйте репозиторий и перейдите в папку проекта:
```bash
git clone https://github.com/EvgeniySpider/Python_OnlineStore_Migun.git
cd Python_OnlineStore_Migun
```

Создайте файл `.env` в корне проекта. Благодаря настроенным fallback-значениям в Docker Compose, для запуска достаточно минимальных настроек:
```env
# Обязательные настройки Django
SECRET_KEY=your_super_secret_key_here
DEBUG=True

# Если вы планируете запускать Django локально (вне Docker), укажите строку подключения
# (Порт 5444 пробрасывается из контейнера БД наружу специально для локальной разработки)
DATABASE_URL=postgres://postgres:postgres@127.0.0.1:5444/store_db
```

### Вариант А: Быстрый запуск полностью в Docker (Сборка + БД + Web)
Идеально для запуска «в один клик». База данных и приложение поднимутся автоматически, миграции применятся при старте.

```bash
docker compose up -d --build
```
Сайт будет доступен по адресу: `http://127.0.0.1:8000/`

Создание суперпользователя внутри контейнера:
```bash
docker exec -it online_store_web python manage.py createsuperuser
```

Наполните базу данных начальными товарами (Сидер):
```bash
poetry run python manage.py seed_db
```

### Вариант Б: Локальная разработка (БД в Docker, Django на хосте)
Идеально для написания кода, прогона тестов и отладки.

1. Запустите только контейнер с базой данных:
```bash
docker compose up -d db
```
2. Установите зависимости проекта через Poetry:
```bash
poetry install
```
3. Примените миграции локально:
```bash
poetry run python manage.py migrate
```
4. Запустите сервер разработки:
```bash
poetry run python manage.py runserver
```

## 🧪 Тестирование и качество кода

Проект полностью покрыт автотестами (Pytest). Тестируются все ключевые сценарии: бизнес-логика корзины и заказов, граничные условия, безопасность и обработка ошибок.

**Запуск тестов:**
```bash
poetry run pytest
```

**Проверка стиля кода (Ruff):**
```bash
poetry run ruff check .    # Линтер
poetry run ruff format .   # Форматтер
```

## ⚙️ Management-команды

В проекте реализованы кастомные команды для управления складскими остатками. 
*(При запуске в Docker добавляйте `docker exec -it online_store_web` перед командой).*

**1. Изменение количества товара на складе**
Увеличить или уменьшить остаток конкретного товара:
```bash
poetry run python manage.py product_quantity increase "Название товара" 10
poetry run python manage.py product_quantity decrease "Название товара" 5
```

**2. Экспорт остатков в JSON**
Выгружает текущее состояние склада в файл:
```bash
poetry run python manage.py export_product_residue --file residue.json
```

**3. Импорт остатков из JSON**
Обновляет базу данных на основе файла:
```bash
poetry run python manage.py load_goods --file residue.json
```
